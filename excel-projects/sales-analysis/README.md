# Sales Data Analysis — Excel Project

## Overview
Analyzed sample sales data to identify revenue trends, top-performing products, and regional performance using Excel.

## Tools Used
- Excel (PivotTables, Charts)

## Key Insights
- USA is the top-selling country, generating $3.6M+ in sales, followed by Spain and France
- Classic Cars is the best-selling product line, generating nearly $3.9M in sales
- Vintage Cars and Motorcycles are the next top-performing categories
